The program is named majvote.cc and is compiled using “g++ majvote.cc”. It is run with “./a.out”. When run, the program will keep prompting the user to enter the number of voters until they enter a number greater than or equal to 3, the minimum number of voters. The program will then keep prompting the user to enter the number of rounds until they enter a valid number of rounds, any number greater than or equal to 1. The program creates a number of pipes equal to the number of voters, forks to create voter IDs for every child process, and the conducts rounds of voting there the parent process (the judge) counts votes the voters made and prints them out, as well as the overall vote for the round, and the child processes (the voters) generate random numbers to decide their votes for each round. After all the voting rounds are finished, each pipe is closed.
